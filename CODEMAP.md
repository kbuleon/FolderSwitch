# Project code map

> Map of the repository's code, built from the sources only.

One line per significant type or file: what it is for. A XAML view and its code-behind (`X.xaml` + `X.xaml.cs`) are one line. Generated code (`bin/`, `obj/`, CsWin32 output) is not listed.

## Repository root

- `FolderSwitch.slnx` — the solution: the four `src/` projects, the five `tests/` projects, `tools/FolderSwitch.IconBuilder`, `tools/FolderSwitch.EmojiData` and `tools/FolderSwitch.DemoGif`.
- `README.md` — the project's presentation, in English; `README.<language>.md` — the same in the eight other languages of the application, each linking to the others.
- `DEVELOPMENT.md` — build, packaging, publishing, tests, diagnostic modes, the README's images, data locations, privacy details and known limits (English only).
- `Directory.Build.props` — settings for every project: nullable on, implicit usings, warnings as errors, latest C#, the version and the copyright, code style checked by the build.
- `.editorconfig` — the license header every C# file must start with (IDE0073, an error at build time).
- `LICENSE` — the GPLv3 text, unchanged; installed next to the executable as `LICENSE.txt`.
- `THIRD-PARTY-NOTICES.txt` — name, version, address, copyright and license of each distributed component (the Unicode CLDR and Emoji data included); installed next to the executable.
- `REUSE.toml` — copyright and license (GPL-3.0-or-later) of the files without a header: icon, screenshots, JSON, project files; the emoji catalog and keyword files are annotated `Unicode-3.0`, the cup of Ko-fi's button as Ko-fi Labs' brand asset.
- `CONTRIBUTING.md` — bug reports and suggestions welcome, code contributions not accepted.
- `SECURITY.md` — security policy: latest version only, private reports through GitHub's vulnerability reporting, scope.
- `.github/ISSUE_TEMPLATE/` — issue forms `bug_report.yml` (version, Windows, steps, expected and actual result, log) and `suggestion.yml`; `config.yml` turns blank issues off.
- `.github/FUNDING.yml` — the repository's « Sponsor » button: the Ko-fi page `karlbuleon`.
- `Directory.Packages.props` — central package versions (xUnit and test SDK; CommunityToolkit.Mvvm, H.NotifyIcon.Wpf, CsWin32, Velopack; Magick.NET for `tools/FolderSwitch.DemoGif`).
- `global.json` — pins the .NET 10 SDK (roll forward to the latest feature band).
- `nuget.config` — nuget.org as the only package source.
- `.config/dotnet-tools.json` — the local tool `vpk` (Velopack packager), same version as the `Velopack` package.
- `build/pack.ps1` — publishes the app (self-contained, ReadyToRun, win-x64) and packs the installer and update packages with `vpk` into `artifacts/releases`; optional code signing; `-ReleaseNotes` puts a notes file in the package.
- `build/release.ps1` — `-Step Prepare` (checks, tests, downloads the previous release, packs with the version's section of `CHANGELOG.md`, and those of the unpublished versions before it, as notes, records `artifacts/release-prepared.json`), `Publish` (tag, draft upload with `vpk upload github`, made visible with `gh`; resumes an interrupted draft) or `All`.
- `build/readme-assets.ps1` — regenerates the README's images in every language (or `-Language`): runs `--snapshot`, copies five 144 DPI images, draws the tour with `tools/FolderSwitch.DemoGif`.
- `assets/icon/` — `FolderSwitch.ico` (9 sizes), `FolderSwitch.svg` (master drawing), `png/FolderSwitch-<size>.png`; generated by `tools/FolderSwitch.IconBuilder`.
- `assets/ko-fi/kofi-cup.png` — the cup of Ko-fi's « Buy me a coffee » button, cropped from Ko-fi Labs' image (not under the GPL), compiled into the executable; `MainView` draws the button around it.
- `assets/screenshots/<language>/` — the README's screenshots of each language (`board.png`, `edit-mode.png`, `icon-picker.png`, `add-menu.png`, `settings-appearance.png`), copied from that language's `--snapshot` output at 144 DPI by `build/readme-assets.ps1`.
- `assets/gif/folderswitch-tour-<language>.gif` — the README's animated tour of each language, drawn by `tools/FolderSwitch.DemoGif`.
- `assets/social/folderswitch-social-preview.png` — the repository's social preview (1280 × 640), uploaded by hand in the GitHub repository's settings; composed once from `assets/icon/FolderSwitch.svg` and `assets/screenshots/en/board.png`, no script redraws it.

## src/FolderSwitch.Core (net10.0)

The domain, with no dependency on Windows, WPF or packages.

### Model/ — the persisted configuration

- `AppConfig` — root: schema version, settings, appearance, tabs.
- `Settings` — language, shortcut, start with Windows, automatic update check, first-run flag, active tab id.
- `Appearance` — mode, theme key, background per `theme:variant`, group corner radius, default column width (220).
- `Tab`, `Column`, `Group`, `Item` — the board tree; ids are GUIDs; a column always has a width once loaded (absent or `null` only in files of versions before 1.12.0); an item has a path, a special-folder key or a web address (`url`), or is a separator (a kind with no name, path or address); a tab and a group have an emoji `Icon` and `IconChosen` (chosen by hand, or automatic).
- `Hotkey` — modifiers plus an optional virtual key (none: modifier-only).
- `KeyModifiers` — flags Ctrl, Alt, Shift, Win.
- `ItemKind` (folder, file, url, separator), `ThemeMode`, `GroupRadius`, `SpecialFolderKey` — the enumerations of the model.
- `ItemNaming` — the displayed name of an item: user name, else translated special-folder name, else the default name of a site (`WebAddress.DefaultName`: host without `www.`, the file name for a `file` address), else last path segment; none for a separator.

### Activation/ — what a click does

- `ActivationRouter` — pure behaviour table: calling context × Windows generation × item kind × Ctrl → an `ActivationPlan`; the plan of « Open in File Explorer », whether Ctrl+click opens a new tab (the item menu), and whether an item can be used from a calling context (`IsUsable`: only folders from a file dialog).
- `ActivationPlan`, `ActivationKind` — the action to run (navigate Explorer, new tab, new window, navigate file dialog, open file, open a web address) and its fallback.
- `ActivationService` — the `IItemActivator`: resolve, check existence within 2 s (a site has neither), route, run the plan with its fallback, map everything to an outcome.
- `ActivationOutcome` — Done (in the calling window), OpenedElsewhere (a new window, a file in its application), TargetUnavailable, Failed, ReportedByShell (the shell showed its own error).
- `ActivationProblem` — an activation that did not simply succeed, for the log: outcome, reason, target, plan, exception.
- `FileNameBoxRule`, `DialogOk`, `DialogMove` — pure rule of the file-dialog navigator: when the file name box may get its text back after an OK.
- `CallContext`, `CallContextKind` — the window FolderSwitch was called from (Explorer, file dialog, browser, other), its handle, current folder and the shell's name for it, and its `BrowserKind` for a browser.
- `FolderLocation` — a folder (path or shell form) and the shell's name for it, as read after the call.
- `BrowserKind` — Firefox, Chrome or Edge.
- `WindowClassifier` — pure: decides Explorer, file dialog (modern or legacy, folder pickers included), browser (process name and window class) or other from a `WindowInfo`.
- `WindowInfo` — class, process and descendant classes and control ids of a window.
- `WindowsGeneration` — Windows 10 or 11.
- `ShellForms` — recognises `shell:` and `::{CLSID}` locations (internal).

### Services/ — ports of the operating system (implemented by the Windows project, except `IItemActivator`, implemented by `ActivationService`, and `IEmojiGlyphs`, implemented by the App)

- `IHotkeyService` — register, probe, capture and trigger of the global shortcut.
- `ICallContextProvider` — captures the foreground window as a `CallContext`.
- `ICurrentFolderReader` — one bounded attempt to read, after the call, the folder an Explorer window or a file dialog shows (`FolderLocation`); `TryReadSelection` makes the same kind of attempt for the selected file (`ExplorerSelection`).
- `ExplorerSelection` — what an Explorer window's active tab selects, as a definite answer: the path of the one selected file (a shortcut's target), or `NoFile`.
- `IExplorerController` — navigate, new tab, new window.
- `IFileDialogNavigator` — move a file dialog to a folder.
- `IItemActivator` — carries out a click on an item and « Open in File Explorer »; tells whether Ctrl+click opens a new tab.
- `IPathResolver` — item to path, and existence check with timeout.
- `IShellLauncher` — open a file, or a site address (`http`, `https`, `ftp`, `file`), with the shell.
- `IBrowserAddressReader` — one bounded attempt to read the address and title of the page a browser window shows.
- `IFavicons` — a site's favicon: the cached file (disk only) and the retrieval (network).
- `IFileTypeIcons` — the small icon Windows gives a file extension, as pixels (`IconPixels`).
- `IForegroundActivator` — bring a window to the foreground; whether the foreground window is one of this process.
- `ISystemInfo` — Windows generation, display language, dark-mode flag and its change event.
- `IAutostart` — start with Windows.
- `IKeyNames` — the names the keyboard layout gives keys.
- `IEmojiGlyphs` — whether the emoji font of the machine can draw an emoji.

### Icons/ — the emoji icons of tabs and groups, pure (no Windows, no WPF)

- `EmojiCategory`, `EmojiEntry` — the eight Unicode groups the catalog keeps; an emoji with its category and its order.
- `EmojiCatalog` — the emojis offered, in catalog order, found with or without their U+FE0F.
- `EmojiKeywords` — the CLDR name and keywords of each emoji, in one language.
- `SynonymTable`, `SynonymConcept` — FolderSwitch's own table of common folder and site words (one chosen emoji per concept, nine languages) and the stop words of each language.
- `EmojiLibrary` — the shipped data (catalog, synonyms, keywords per language) read from a folder; a language is read when first asked for, then kept.
- `IconFinder` — over the library and `IEmojiGlyphs`: the emojis the font can draw, the icon a name suggests (synonyms first, then the keywords of the current language, then English's), the filter of the picker, the name of an emoji; its indexes are built at first use.
- `IconWords` — cuts a name or a typed filter into words: lower case, no accents, singular, stop words left out.
- `IconText` — structural check of an icon's text (one emoji, not a word), so that damaged text is never shown as an icon.

### Hotkeys/ — pure shortcut logic

- `HotkeyRules` — validation (single modifier, no modifier, reserved by Windows, Ctrl+Alt warning), blocking rule, display formatting (layout key names through `IKeyNames`, key-cap fallback names).
- `HotkeyIssue` — the problems a shortcut can have.
- `ModifierChordDetector` — state machine for a modifier-only chord triggered on release, fed key events by the hook.
- `ChordStep` — the detector's answer: trigger, suppress the Start menu.
- `VirtualKeys` — virtual-key codes used and their mapping to `KeyModifiers`.

### Layout/

- `ColumnWidths` — column width limits (150–520, step 10), the default width (220) and `Clamp` (nearest step, within the limits).
- `WindowPlacement` — centering on a work area, re-anchoring (keep top edge and horizontal centre), fitting a dropped window back inside and clamping to a work area, in DIPs.
- `SizeD`, `RectD` — size and rectangle in DIPs.

### Editing/

- `BoardEditor` — every edit of the board as a pure operation on `AppConfig` (tabs, columns, groups, items, rename, icon, move within or across tabs, collapse, colour, width, the widths of a tab made equal, one random palette colour per column with neighbours different); a tab keeps at least one column.
- `EditResult`, `EditError` — success or the reason an edit was refused (an invalid icon included).

### Persistence/

- `ConfigSerializer` — JSON read and write; strict structure, tolerant content (normalisation, an `url` item without a valid site address dropped, a separator stripped of any name or target, an icon that is not an emoji dropped, a column without width given the default width, widths clamped); schema version check (current: 3, versions 1 and 2 read as is; a separator is written with `id` and `kind` only); the `icon` property written as is, not escaped.
- `ConfigStore` — `config.json` in `%APPDATA%\FolderSwitch`: atomic, flushed save, load with repair, rolling backups, atomic export, import.
- `LoadResult`, `LoadOutcome` — how a load ended (loaded, created, restored from backup, reset).
- `DefaultConfigs`, `StartContent` — the first-run configuration (sample tab or empty tab); its names are given their automatic icons.
- `ConfigFormatException` — a text that is not a usable configuration.

### Localization/

- `Localizer` — loads `<code>.json` files, current language, fallback lookup, `Format`, `LanguageChanged`.
- `Languages` — pure rules: initial language from the Windows language, fallback chains.

### Theming/

- `ThemeCatalog` — the seven themes in two variants, group palette, background tints, token resolution with background contrast correction.
- `ThemeTokens` — resolved colours and metrics of a theme.
- `GroupStyle` — how a group is drawn (one per theme).
- `GroupVisuals`, `GroupVisual`, `CountBadgeVisual` — a group's colours from its style and colour; item-count badge colours.
- `ColorMath` — hex colour parsing, mixing, WCAG contrast, contrast-correcting search.
- `NamedColor`, `Variant` — a catalog colour; light or dark.

### SpecialFolders/

- `SpecialFolderCatalog` — the 16 special folders in offer order, with localization key and storage form.
- `SpecialFolderInfo`, `SpecialFolderCategory` — one entry; personal or system.

### Web/ — web sites, pure (no Windows, no WPF)

- `WebAddress` — validation and normalisation of an `http`, `https`, `ftp` or `file` address (`https://` added when there is no scheme; credentials refused), `IsSiteUrl`, `WebHost` (`http`/`https` only: the favicon's host), host label without `www.`, `DefaultName`, `LocationLabel` (host, or the Windows path of a `file` address), same-site comparison.
- `BrowserPage` — the address and title read from a browser window.
- `BrowserTitle` — the page title out of a browser's window title (suffix, private-window and profile marks removed).
- `FaviconFetcher` — retrieves a favicon over an `HttpMessageHandler`: the page, the icons it declares, then `/favicon.ico`; bounded time, size and redirects, each redirect checked.
- `FaviconLinks` — finds the candidate icon addresses in a page's HTML (`<link>` and `<base>` tags).
- `FaviconFormat` — recognises an ICO, PNG, GIF, JPEG or BMP by its first bytes; anything else is refused.
- `FaviconCache` — one file per host, in lower-case punycode, in a folder; atomic write.
- `Favicons` — `IFavicons` over the cache and the fetcher; one log line per failure.

### Updates/

- `UpdateAnnouncements<TVersion>`, `AutomaticOffer` — remembers the newest version whose box opened, so a box opens once per version per session, and the version the periodic check found that waits for its box; decides whether that box opens now or is postponed (FolderSwitch in use).

### Diagnostics/

- `CriticalExceptions` — the exception types after which the process cannot be trusted (out of memory, stack, native fault), wrapped ones included; what catch-alls let through.

## src/FolderSwitch.Presentation (net10.0)

View models and the UI-facing ports. Depends on Core and CommunityToolkit.Mvvm.

### Services/

- `IConfigPersistence` — save the configuration after every change.
- `IUserPrompts` — confirmations, errors, file pickers (`PickFile` opens in a given folder) and folder pickers, the web address prompt, export and import paths.
- `IWindowHost` — hide the main window.

### ViewModels/

- `MainViewModel` — the window: board projection, normal use and Customize mode, all edits, rename (the automatic icon of the new name), the icon commands and the opening of the icon picker, activation and its outcomes, which items the calling window can use, adding a site (and fetching its favicon: at once, and once per host per session when missing), opening the Add menu, tab shown during a drag across tabs, `OnShown`/`OnHidden`/`OnDeactivated`, `Reload` after an import; the Edit-mode tools (equalize the widths of the tab, random colours per column) and the reset of a column to the default width.
- `AddMenuViewModel` — the « Add ▾ » menu of a group: the top block for the calling window (« Current folder » or the page, « File from current folder… », « Selected file »), the footer, the additions; reads a browser's page, a folder the call could not read, and (Explorer only) the selected file, while the menu is open (every 200 ms, for 2 s), and stops when disposed.
- `UrlPromptViewModel` — the web address prompt: prefill (a browser's page or the clipboard), validation, the normalised result.
- `TabViewModel`, `ColumnViewModel`, `GroupViewModel`, `ItemViewModel` — projections of the model objects; a tab and a group carry their `Icon` and `HasIcon`, empty when the font cannot draw it.
- `IconPickerViewModel`, `IconSection` — the icon picker of a tab or group: the filter, « Automatic » and « No icon », the categories and their emojis, the current choice; a choice is carried out by the main view model.
- `IconChoice` — what the icon currently is: automatic, none chosen, or a chosen emoji.
- `RenamableViewModel` — base of the three nameable objects (tab, group, item).
- `InsertionSlot` — converts a drop slot into the index the model expects.
- `SpecialFolderState` — one entry of the Add menu's special folders (name, already present).
- `AppearanceViewModel` — mode, theme, background, corners, default column width; resolves the effective variant (live Windows mode) and raises `AppearanceChanged`.
- `AppearanceChangedEventArgs` — the new tokens and radius.
- `SettingsViewModel` — language, shortcut, start with Windows, export, import (`ConfigReplaced`), update check, automatic update check (`CheckForUpdatesAutomatically`, `AutomaticUpdatesChanged`).
- `LanguageOption` — a selectable language.
- `HotkeyEditorViewModel` — shortcut display, issues, keyboard capture, test zone (tests only the shortcut in effect); shared by settings and wizard.
- `HotkeyIssueMessage` — an issue explained in the current language.
- `WizardViewModel` — the four steps of the first-run wizard and the configuration it creates, whose sample tab and group get automatic icons.
- `WizardHotkeyTest` — registers the candidate shortcut temporarily for the wizard's test zone.
- `HotkeyTestRefusal` — a registration the test zone could not make.

## src/FolderSwitch.Windows (net10.0-windows)

Implements the Core ports against Win32, COM and the registry. `NativeMethods.txt` lists the Win32 APIs CsWin32 generates.

### Hotkeys/

- `HotkeyService` — `IHotkeyService`: own high-priority thread and message-only window, `RegisterHotKey`, the low-level hook with the chord detector, mask key, capture, session and resume notifications, periodic re-arm of the hook.
- `KeyNames` — `IKeyNames` with `MapVirtualKey` and `GetKeyNameText`.
- `LowLevelKeyboardHook` — the `WH_KEYBOARD_LL` hook (internal).
- `RegisteredHotkey` — a `RegisterHotKey` registration (internal).
- `KeyboardSystem.cs` — `IKeyboardSystem` seam and its Win32 implementation (mask key injection, async key state).

### Browsers/

- `BrowserAddressReader` — `IBrowserAddressReader`: reads the address bar and the page document of a Firefox, Chrome or Edge window through UI Automation, on its own STA thread, one attempt bounded at 500 ms.
- `DocumentGraceTracker` — per window, how long an address bar has gone without a confirming page document within a series of attempts (internal).

### Shell/

- `ExplorerController` — `IExplorerController`: navigate the active tab with an ID list, new tab (undocumented command), new window; bounded STA worker.
- `ExplorerWindows`, `ExplorerBrowser`, `ShellLocation` — enumeration of open Explorer browsers through `IShellWindows`, their current folder with its shell name, and the file selected in the active tab (a shortcut's target; internal).
- `ShellInterop.cs` — hand-declared shell COM interfaces and the `ShellNative` helpers (ID lists, parsing names, `ShellExecuteEx`).
- `ShellLauncher` — `IShellLauncher`: opens files, locations and site addresses (`http`, `https`, `ftp`, `file` only) with `ShellExecuteEx` on an STA thread; a failed launch has shown the shell's own error.
- `FileTypeIcons` — `IFileTypeIcons`: the icon of an extension from the shell's registry data, without touching a file (`SHGetFileInfo`), on its own STA thread, bounded, one answer kept per extension.
- `ShellNamespace` — resolves displayed folder names back to a parsing name by walking the shell namespace.
- `WindowInspector` — class, process and bounded descendant listing of a window without messaging it (internal).

### Dialogs/

- `FileDialogNavigator` — `IFileDialogNavigator`: moves Open, Save As and folder-picker dialogs to a folder, with verification and retry.
- `FileDialogInspector` — reads the folder a dialog shows, per dialog family (internal).
- `RemoteMemory` — memory block in the dialog's process for messages carrying pointers (internal).
- `WindowMessages` — `SendMessageTimeout` helpers (internal).

### System/ (namespace `FolderSwitch.Windows.SystemServices`)

- `CallContextProvider` — `ICallContextProvider` and `ICurrentFolderReader`: classification (the browser kind included; nothing is read from the browser) plus bounded folder (and shell name) lookup on an STA worker, each worker warmed up first; the same lookup, with 500 ms, for a folder the capture missed, and the same worker and gate for the selected file (`TryReadSelection`).
- `StaWorker` — dedicated STA thread running timed work items, with an optional clean-up when it ends; abandonment semantics (internal).
- `PathResolver` — `IPathResolver`: special folders and environment variables to paths; bounded existence checks with abandoned-probe limits, per UNC share and mapped network drive.
- `ForegroundActivator` — `IForegroundActivator`, with the attached-input fallback; foreground ownership by process id.
- `SingleInstance` — session mutex and activation event.
- `Autostart` — `IAutostart` over the current user's `Run` registry key.
- `SystemInfo` — `ISystemInfo`: Windows generation, display language, dark-mode registry value and its change watch.
- `DisplayMonitors`, `MonitorWorkArea`, `MonitorPoint` — the cursor or a window's corner with the work area of its monitor, or the primary work area, with DPI scale; move a window in pixels.
- `WindowFrame` — rounded corners and shadow of a borderless window.
- `WindowsVersion` — Windows 11 detection by build number (internal).

## src/FolderSwitch.App (net10.0-windows, WPF, executable `FolderSwitch.exe`)

The shell and composition root.

### Root

- `Program` — entry point: Velopack hooks, option parsing, log, single instance, runs the application; `--self-test`, `--snapshot`.
- `App` (`App.xaml`) — the resident WPF application: startup, ready signal, startup notices, self-test watchdog, UI exception policy and breaker, quit.
- `UpdateFeed` — the compile-time address of the GitHub repository whose releases are read; `TryParseRepository` accepts only `https://github.com/<owner>/<repository>` and `CreateSource` builds the Velopack `GithubSource` (no token, no prerelease), `null` for any other address (updates off).
- `app.manifest` — `asInvoker`, per-monitor-v2 DPI, Windows 10/11 compatibility.
- `Strings/*.json` — the nine translation files (`en`, `de`, `es`, `fr`, `it`, `nl`, `pl`, `pt-BR`, `pt-PT`), copied next to the executable.
- `Emoji/` — the emoji data of the icons, copied next to the executable as `Emoji\`: `catalog.json` (781 emojis in eight categories) and `keywords/<code>.json` (nine files), made by `tools/FolderSwitch.EmojiData` from Unicode files and under the Unicode License v3; `synonyms.json`, the project's own table of common folder and site words.

### Startup/

- `Composition` — builds and releases everything in order; owns the services (the browser reader, the file type icons, the favicon connections), view models, window, icon, update checker; starts the loading of the emoji data in the background.
- `StartupOptions` — what `Main` hands to the app (self-test, config folder, clock, UI context, instance, setup notice).
- `SetupNotice`, `SetupKind` — an installation or an update reported by Velopack's hooks, and the text of the box that says so.
- `WindowController` — shows, hides, recalls (to the front, new calling window), places (always centered on the work area of the monitor under the cursor) and pre-renders the main window; follows a drag of it and fits the drop inside its monitor; captures the call context first; tells the view model of every hide; returns focus to the calling window (`IWindowHost`); brings an open box of FolderSwitch's to the front for the shortcut.
- `ShortcutRouting`, `ShortcutAction` — pure: what a press of the shortcut does (show, hide, recall, test zone, bring the open box to the front, nothing).
- `FocusReturningActivator` — decorates the activator to tell the controller which window to give focus back to.
- `FirstRunWizard` — runs the wizard modally with its theme and shortcut test, before the rest is built.
- `UpdateChecker`, `UpdateAvailability` — Velopack check, offer, download and apply; timer and busy state; the periodic check's box postponed (one-minute retry) while FolderSwitch is in use; `SetAutomatic` starts or stops the periodic check; no checker for an address that is not a GitHub repository.

### Services/

- `ConfigPersistence` — `IConfigPersistence` over `ConfigStore`: failures logged and reported once; read-only session mode.
- `UserPrompts` — `IUserPrompts`: themed message boxes, Windows file and folder pickers (the file picker opens in the folder it is given), the web address prompt, update offer (never owned, on top, without taking focus, when the periodic check makes it); the box open now, for the shortcut; silent mode.

### Diagnostics/

- `DebugLog` — local rolling log file (`logs\folderswitch.log`); a failed roll keeps logging in the current file.
- `ExceptionPolicy` — which exceptions are critical (the process must end).
- `ErrorBreaker` — counts handled UI exceptions; trips at five within ten seconds.
- `Snapshots/SnapshotRunner` — renders every look, interaction and wizard step to PNG off-screen.
- `Snapshots/SnapshotSample` — the sample configuration of the snapshots (files of several types, sites, a separator, icons on tabs and groups), in the snapshot's language.
- `Snapshots/SampleNames` — the words of the sample configuration in each of the nine languages (names, file names, folders of the paths), also the names the runner looks groups up by.
- `Snapshots/SnapshotServices` — inert implementations of every service the view models need (one favicon file, a browser page), and the real emoji data from the build's `Emoji` folder.

### Themes/

- `ThemeApplier` — turns appearance tokens into the `Fs.*` application resources and swaps them on change; installs the shared styles.
- `ThemeKeys` — the names of those resources.
- `AppearanceState` — theme, variant, tokens and radius as one resource value.
- `GroupStyleSelector`, `GroupLook` — a group's brushes, thicknesses and effects for its colour in the current appearance.
- `WizardTheme` — the wizard's own look, before any configuration exists.
- `Generic.xaml` — shared styles, converters, glyph geometries; no colours.

### Tray/

- `TrayIcon` (`TrayIcon.xaml`) — the notification-area icon and menu; update entry; the ready notification of the first run.
- `TrayIconImage` — loads the right icon size for the system scale.

### Views/

- `MainWindow` — the borderless resident window: frame, keyboard (Tab, Escape, F2), hide on close.
- `MainView` — the window's content: title bar (with ⚙ and (?), and in Customize mode Ko-fi's button after the name, which opens the author's Ko-fi page, and a small toolbar left of « Done »: equalize widths, random colours), tab bar, the boards of every tab (the active one shown); flyout host; dialog layer (settings and About over a dimmed backdrop); rename focus handling.
- `TabBar`, `BoardView`, `ColumnView`, `GroupView`, `ItemView` — the board's views (the tab bar wraps, and shows the tab a drag rests on; a tab and a group header show their icon left of the name, or a discreet slot in Customize mode); Customize-mode gestures and drop targets.
- `ColumnResizeGrip` — drag a column's width, double-click for the default width.
- `AppearanceMenu` — the settings' Appearance page: mode, theme tiles, backgrounds, corners (with `ThemeTile`, `ModeChoice`, `BackgroundSwatch`, `RadiusChoice`).
- `ThemePreview` — a theme's thumbnail drawn with the real catalog colours.
- `SettingsView` — the settings window: categories (`SettingsPage`, `SettingsPageChoice`) and their pages (General: language, autostart, the default column width, updates and the automatic check, version; Shortcut; Appearance; Configuration: import/export).
- `AboutView` — the About window: icon, name, version, description; the legal notices (copyright, license, no warranty) with links that open `LICENSE.txt` and `THIRD-PARTY-NOTICES.txt` next to the executable.
- `AddMenu` — the « Add ▾ » menu of a group: current folder or URL, file from current folder, selected file, folder, special folders, file, URL, separator, footer (with the `SpecialFolderEntry` record).
- `UrlPromptView` — the content of the web address prompt (shown in a `PromptWindow`).
- `ItemIcon.cs` — `ItemIcons`: the pictures of the items that do not come from the application (a file type's icon, a favicon), made off the UI thread and kept for the process.
